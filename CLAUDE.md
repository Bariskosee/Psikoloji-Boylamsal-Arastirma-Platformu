# CLAUDE.md

This repository contains the **Longitudinal Psychology Research Platform**, a privacy-sensitive research application for longitudinal questionnaires, repeated-measures studies, ESM/EMA-style workflows, participant reminders, and researcher monitoring.

## Mandatory instruction

**Before planning, editing, generating, refactoring, or reviewing code in this repository, look at and read `@AGENT.md` in full.**

`AGENT.md` is the primary operating contract for AI-assisted development in this repository. Its instructions apply to architecture, security, privacy, data integrity, testing, notifications, scheduling, UX, and scope control.

Also consult the following documents when relevant:

- `README.md` — project overview and product intent.
- `REQUIREMENTS.md` — normative functional and non-functional requirements.
- `STRUCTURE.md` — target repository and system architecture.
- `PLAN.md` — phased implementation plan and definition of done.

## Priority of project documentation

When repository documents appear to conflict, use this order unless a human maintainer explicitly says otherwise:

1. Explicit instructions from the human maintainer in the current task.
2. `REQUIREMENTS.md` for product behavior and acceptance criteria.
3. `AGENT.md` for engineering and agent behavior.
4. `STRUCTURE.md` for architectural boundaries and repository organization.
5. `PLAN.md` for implementation sequence.
6. `README.md` for high-level context.

Do not invent research instruments, questionnaire content, consent language, clinical interpretations, or ethics claims. Use placeholders when those inputs have not been provided by the research team.
